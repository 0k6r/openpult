# openpult

**Открытая BLE → ИК-приставка и пульт на iPhone для любого телевизора.**
Маленькая коробочка на батарейках стоит перед телевизором и превращает команды приложения, приходящие по
Bluetooth, в инфракрасный сигнал — такой же, как у родного пульта. Подходит для телевизоров со сломанным Wi‑Fi,
старых кинескопных и вообще любой техники с ИК-пультом.

[English version](README.md)

- **Любой телевизор.** Приставка проигрывает любой ИК-сигнал: несущую, длительности импульсов, повторы.
  - Протоколы живут в приложении: NEC, Samsung, Sony SIRC, Philips RC5/RC6, Panasonic (Kaseikyo), RCA и другие.
  - Коды телевизоров приложение по кнопке скачивает из [Flipper-IRDB](https://github.com/Lucaslhm/Flipper-IRDB) (≈1,3 МБ).
  - С дополнительным приёмником приставка **обучается** кнопкам родного пульта.
- **Год на батарейках AA.** Плата nRF52840 и 3 элемента AA. Приставка напоминает о себе раз в ~0,5 с и держит связь,
  только пока открыто приложение.
- **Легко собрать самому.** Деталей примерно на $10 с AliExpress, несколько паек, корпус на 3D-принтере.
- **Sony BRAVIA по Wi‑Fi.** С Android-телевизорами Sony приложение умеет работать и по домашней сети (Sony IP Control).
- **Интерфейс на русском и английском.**

## Как это работает

```
Приложение ──BLE──▶ приставка (nRF52840) ──ИК 940 нм──▶ датчик ТВ
  кодировщики,           проигрывает сигнал:
  профили брендов,       несущая + длительности + повторы
  распознавание
```

## Что понадобится

| Деталь | Комментарий |
|---|---|
| Плата nRF52840 | SuperMini / клон nice!nano (рекомендуется), Seeed XIAO nRF52840, Adafruit Feather nRF52840, донгл nRF52840 |
| ИК-светодиод 940 нм, 5 мм, и резистор 180–220 Ом | прямо от вывода платы, на 5–20 см; для большей дальности — транзистор |
| Отсек на 3×AA и диод Шоттки (1N5817 / BAT43) | или 3×AAA, Li-ion, питание от USB |
| ИК-приёмник VS1838B / TSOP38238 (по желанию) | чтобы обучить коды с родного пульта |
| Выключатель SS12D00, кнопка 6×6 мм (по желанию) | питание и вход в режим прошивки |

Подробно: [платы](docs/hardware/boards.md), [схемы подключения](docs/hardware/wiring.md),
[питание](docs/hardware/power.md).

## Быстрый старт

1. **Соберите приставку** — [docs/hardware/wiring.md](docs/hardware/wiring.md).
2. **Прошейте** — скачайте `.uf2` для своей платы из Releases, дважды замкните reset и скопируйте файл на появившийся
   диск. Сборка из исходников: [docs/firmware/build.md](docs/firmware/build.md).
3. **Напечатайте корпус** — [docs/enclosure/printing.md](docs/enclosure/printing.md).
4. **Установите приложение** — понадобятся Xcode и бесплатный Apple ID: [docs/app/install.md](docs/app/install.md).
5. **Подключите и выберите ТВ** — включите приставку, выберите её в приложении в течение 2 минут, скачайте базу кодов,
   затем выберите бренд телевизора, подберите код автоматически или обучите кнопки.
